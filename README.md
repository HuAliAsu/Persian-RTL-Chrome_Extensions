# فونت فارسی و راست‌چین خودکار برای Chrome

افزونه‌ای مبتنی بر Manifest V3 برای خواناتر کردن متن فارسی و عربی در وب‌سایت‌ها، به‌ویژه سرویس‌های گفت‌وگومحور هوش مصنوعی. افزونه فونت فارسی را فقط روی متن مرتبط اعمال می‌کند و برای بلوک‌های مناسب، جهت متن را بر اساس وجود کلمهٔ فارسی یا عربی در متن تشخیص می‌دهد.

![آیکون افزونه](icon-public.svg)

## قابلیت‌ها

- فعال‌سازی با یک کلیک: کلیک روی آیکون افزونه در سایتی که هنوز فعال نیست، همان سایت را فعال می‌کند (هم فونت و هم RTL)؛ کلیک بعدی روی سایتی که فعال است، popup تنظیمات را باز می‌کند.
- نشانگر بصری وضعیت: در سایت‌های فعال، یک نقطهٔ سبز روی آیکون افزونه نمایش داده می‌شود.
- تشخیص جهت متن به‌صورت پیش‌فرض بر اساس وجود هر کلمهٔ کامل فارسی یا عربی در هر جای متن؛ حالت قدیمی‌تر («فقط اولین کلمهٔ پاراگراف») هم از طریق یک سوییچ در popup قابل‌فعال‌سازی است.
- اعمال RTL فقط روی بلوک‌های متنی مناسب مانند پاراگراف، فهرست، عنوان، نقل‌قول و سلول جدول.
- حفظ جهت اصلی سایت؛ با غیرفعال‌شدن سایت یا کل افزونه، attributeهای افزونه پاک می‌شوند.
- پشتیبانی از `textarea`، ورودی متنی و editorهای `contenteditable` با `dir="auto"` برای تایپ و paste فارسی.
- استثنا برای code block، terminal، MathJax، KaTeX، Monaco و CodeMirror تا LTR باقی بمانند.
- پشتیبانی از پاسخ‌های streaming، برنامه‌های SPA، iframeهای مجاز و Shadow DOM باز به‌صورت best effort.
- پنج فونت فارسی سبک (Vazirmatn، Samim، Sahel، Gandom، Mikhak) به‌علاوهٔ گزینهٔ «بدون تغییر فونت» برای زمانی که فقط RTL مدنظر است.
- به‌روزرسانی امن تنظیمات قدیمی؛ انتخاب سایت‌ها و مسیرهای قبلی کاربران حفظ می‌شود.

## نصب

repository را clone کنید، یا با اسکریپت `scripts/build-package.ps1` یک ZIP بسازید (بخش «ساخت بسته» را ببینید). سپس در Chrome:

1. به `chrome://extensions` بروید.
2. گزینهٔ **Developer mode** را فعال کنید.
3. روی **Load unpacked** کلیک کنید.
4. پوشهٔ ریشهٔ repository (یا پوشهٔ extract‌شدهٔ ZIP) را انتخاب کنید.

پس از تغییر فایل‌های افزونه، در صفحهٔ extensions روی دکمهٔ reload افزونه کلیک کنید.

## استفاده

- کلیک روی آیکون افزونه در سایتی که هنوز فعال نیست، همان سایت را فعال می‌کند. کلیک روی آیکون در سایت فعال، popup تنظیمات را باز می‌کند.
- **فعال برای این سایت** در بالای popup هم همین وضعیت را نشان می‌دهد و امکان خاموش‌کردن دستی را می‌دهد.
- **تشخیص فقط بر اساس کلمهٔ اول پاراگراف** حالت قدیمی‌تر تشخیص جهت را فعال می‌کند؛ پیش‌فرض خاموش است.
- **انتخاب فونت** و **بزرگ‌نمایی** فقط روی متن فارسی اعمال می‌شوند؛ گزینهٔ «بدون تغییر فونت» فقط RTL را فعال نگه می‌دارد.
- **غیرفعال کردن کل افزونه** هم فونت و هم RTL را در همهٔ سایت‌ها، بدون تغییر تنظیمات ذخیره‌شده، متوقف می‌کند.

## منطق جهت متن

در حالت پیش‌فرض (`anyWord`)، وجود یک کلمهٔ کامل فارسی یا عربی در هر جای متن کافی است تا کل بلوک RTL شود:

- `سلام دنیا`، `123 - سلام` و `Use متغیر in this code` به‌صورت RTL پردازش می‌شوند.
- `Hello world` به‌صورت LTR باقی می‌ماند.
- `۱۲۳۴` خنثی است و جهت جدیدی به آن تحمیل نمی‌شود.

در حالت قدیمی‌تر (`firstStrong`، از طریق سوییچ popup)، فقط اولین نویسهٔ دارای جهت قوی در متن تعیین‌کننده است؛ برای مثال `Use متغیر in this code` در این حالت LTR می‌ماند چون با حرف لاتین شروع می‌شود.

برای جلوگیری از تغییر ناخواستهٔ متن انگلیسی، فقط بلوک‌هایی که نتیجهٔ آن‌ها RTL است با `data-persian-direction="rtl"` علامت‌گذاری می‌شوند. متن LTR و خنثی دست‌نخورده باقی می‌ماند.

## توسعه و تست

پیش‌نیازها:

- Node.js 20 یا جدیدتر
- Python 3 برای بررسی JSON و ZIP
- Google Chrome برای تست دستی افزونه

```powershell
npm.cmd test

node --check core.js
node --check background.js
node --check content.js
node --check popup.js
node --check sites.js
python -m json.tool manifest.json
git diff --check
```

تست‌های خودکار تابع تشخیص جهت، migration تنظیمات، تطبیق hostname/path و fallback فونت‌های حذف‌شده را پوشش می‌دهند.

## ساخت بسته

ساخت ZIP عمومی:

```powershell
.\scripts\build-package.ps1 -Flavor public
```

خروجی در `dist/Farsi_Font_Chrome_Extension.public.zip` نوشته می‌شود و با `python -m zipfile -t` اعتبارسنجی می‌شود. فایل عمومی فقط از آیکون عمومی repository استفاده می‌کند.

## ساختار پروژه

```text
.
├── background.js          # migration و lifecycle افزونه
├── content.js             # موتور فونت، RTL و observerها
├── core.js                # منطق خالص detector و site rules
├── fonts/                 # پنج فونت همراه افزونه
├── popup.*                # تنظیمات سریع افزونه
├── sites.*                # فهرست سایت‌های فعال
├── scripts/               # ساخت بستهٔ release
└── tests/                 # تست‌های Node.js
```

## محدودیت‌ها

- Shadow DOM بسته قابل دسترسی نیست.
- افزونه روی صفحه‌های داخلی Chrome و برخی URLهای محدودشده اجرا نمی‌شود.
- پشتیبانی از DOM سرویس‌های ثالث با تغییر ساختار آن سایت‌ها ممکن است نیازمند اصلاح شود.
- تست سایت‌های نیازمند login باید با حساب آزمایشی و افزونهٔ unpacked انجام شود.

## حریم خصوصی

افزونه متن صفحه را به سرویس خارجی ارسال نمی‌کند. تمام تشخیص جهت و اعمال فونت داخل مرورگر انجام می‌شود.
